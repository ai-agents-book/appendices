# AI Agents — Appendices

The appendices to *AI Agents: Designing, Orchestrating, and Governing
LLM-Based Systems* by Michael Bücker and Michael Hewing.

**Read them at <https://ai-agents-book.github.io/appendices/>**, or download
[`appendices.pdf`](https://ai-agents-book.github.io/appendices/appendices.pdf).

## What is here

| Appendix | What it covers |
| --- | --- |
| **A. Python Setup** | Installing Python and `uv`, the project's dependencies, environment variables and API keys, and running a first example. |
| **B. Python and API basics** | Enough Python to read, run, and adapt the book's listings: types, collections, functions, classes, JSON, and calling and building web APIs. A reference, not a full course. |
| **C. Deep learning** | The layer beneath the models chapter: vectors and matrices, softmax, neural networks, backpropagation, optimization, regularization, and common failure modes. |

Appendix A is the one to read first if you want to run the code. Appendix B
assumes you program in some language but not necessarily in Python. Appendix C
is background for readers who want the mathematics the models chapter uses
without defining.

## Why they are not in the printed book

Keeping them here rather than in print means the parts that age fastest, the
package versions, the setup steps, and the provider-specific API details, can
be corrected while the edition is in use. The printed book points to this
repository in its place.

## About this repository

This repository holds rendered output only. The appendices are written and
maintained alongside the manuscript and rendered from it, so edits to the HTML
or the PDF here are overwritten by the next render. Corrections and questions
are welcome as [issues](https://github.com/ai-agents-book/appendices/issues).
